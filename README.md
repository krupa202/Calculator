# Calculator

A simple calculator built using HTML, CSS, and JavaScript. It performs basic mathematical operations through an easy-to-use interface.

## Technologies Used
- HTML – To create the calculator structure.
- CSS – To style the calculator.
- JavaScript – To perform calculations and handle button clicks.

## Features
- Addition, subtraction, multiplication, and division.
- Percentage calculation.
- Clear (AC) and Delete (DE) buttons.
- Decimal number support.
- Simple and user-friendly interface.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Type
Frontend Mini Project
